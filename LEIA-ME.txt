MENTE EM DIA — FMU TECH
INSTRUÇÕES DE INSTALAÇÃO, INICIALIZAÇÃO E AVALIAÇÃO
============================================================

ATENÇÃO — LEIA ANTES DE ABRIR O SISTEMA

O Mente em Dia NÃO é um site estático. Ele utiliza um servidor local
feito em JavaScript (Node.js) e um banco de dados SQLite.

PORTANTO, É OBRIGATÓRIO INICIAR O SERVIDOR ANTES DE ACESSAR O APLICATIVO.
Se o servidor não estiver iniciado, o endereço do sistema não carregará
corretamente. NÃO abra o arquivo index.html com dois cliques.

RESUMO PARA QUEM VAI AVALIAR

1. Instale o Node.js versão 22.13 ou superior.
2. Inicie o servidor usando node server.js no terminal, ou dê dois cliques
   no arquivo INICIAR_MENTE_EM_DIA.bat (Windows).
3. Mantenha a janela do servidor aberta.
4. Só então acesse http://localhost:3000 no navegador.

------------------------------------------------------------
1. O QUE PRECISA ESTAR INSTALADO
------------------------------------------------------------

- Node.js versão 22.13 ou superior: https://nodejs.org/
- Visual Studio Code: opcional, mas recomendado.
- Navegador atualizado (Chrome, Edge ou Firefox).

Não é necessário instalar bibliotecas ou dependências externas para
executar esta versão. O projeto utiliza recursos nativos do Node.js.

------------------------------------------------------------
2. COMO INICIAR PELO VISUAL STUDIO CODE (WINDOWS)
------------------------------------------------------------

1. Extraia o ZIP completo para uma pasta do computador.
2. Abra no Visual Studio Code a pasta:
   Mente_em_Dia_Arquivos_Separados
3. No menu superior, clique em Terminal > Novo Terminal.
4. Confira se o terminal está apontando para a pasta do projeto, onde está
   localizado o arquivo server.js.
5. Digite o comando abaixo e pressione Enter:

   node server.js

   Alternativamente, se preferir, execute:

   npm start

6. Aguarde a mensagem indicando que o servidor do Mente em Dia foi iniciado.
7. MANTENHA O TERMINAL ABERTO enquanto estiver usando ou avaliando o sistema.
8. Abra uma nova aba do navegador e acesse:

   http://localhost:3000

IMPORTANTE: o endereço acima deve ser aberto somente DEPOIS que o servidor
estiver iniciado. Não tente abrir index.html diretamente.

------------------------------------------------------------
3. INICIALIZAÇÃO MAIS SIMPLES (WINDOWS)
------------------------------------------------------------

Se o Node.js já estiver instalado:

1. Abra a pasta Mente_em_Dia_Arquivos_Separados.
2. Dê dois cliques em INICIAR_MENTE_EM_DIA.bat.
3. Aguarde o servidor iniciar e mantenha a janela aberta.
4. Acesse http://localhost:3000 no navegador.

Se aparecer uma mensagem informando que o Node.js não foi encontrado,
instale a versão 22.13 ou superior e tente novamente.

------------------------------------------------------------
4. COMO ENCERRAR O SERVIDOR
------------------------------------------------------------

Quando terminar a avaliação, volte à janela do terminal/servidor e
pressione Ctrl + C.

------------------------------------------------------------
5. BANCO DE DADOS SQLITE
------------------------------------------------------------

O banco é criado automaticamente na primeira inicialização, dentro da pasta:

database/mente_em_dia.sqlite3

Ele armazena localmente os dados utilizados pelo aplicativo, como perfil,
check-ins e registros do diário emocional. Não é necessário criar o banco
manualmente. Para preservar os dados, encerre o servidor e faça uma cópia
desse arquivo.

------------------------------------------------------------
6. OBSERVAÇÕES IMPORTANTES
------------------------------------------------------------

- O servidor é local e roda no próprio computador. Não é uma hospedagem
  pública na internet.
- O servidor precisa permanecer em execução durante o uso do aplicativo.
- O endereço correto para acessar o sistema é http://localhost:3000.
- Não abra index.html diretamente pelo explorador de arquivos.
- O banco SQLite fica neste computador; esta versão não possui login,
  contas individuais ou sincronização entre computadores.
- Antes de qualquer uso real com estudantes, são necessárias medidas
  adicionais de autenticação, autorização, segurança e proteção de dados,
  política de privacidade, backups seguros e validação institucional.
  O diário emocional pode conter informações pessoais sensíveis.

O vídeo de abertura, a identidade visual Mente em Dia e a identificação
FMU Tech fazem parte do projeto.
